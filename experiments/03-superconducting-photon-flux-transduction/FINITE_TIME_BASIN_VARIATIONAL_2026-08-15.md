# Variational Pullback of the Finite-Time Basin Normal — 2026-08-15

## Purpose

Provide an efficient local calculation of the pulled-back finite-time basin boundary once a boundary trajectory has been identified by shooting.

A direct scan of `v_edge(x)` at many nearby initial phase coordinates is expensive. The local tangent/normal can instead be propagated analytically through the variational flow.

This is standard dynamical-systems machinery applied to Experiment 03 and is not a novelty claim.

## 1. Phase-space flow

For the current deterministic scalar-R model,

```math
z=\begin{pmatrix}x\\v\end{pmatrix},
```

```math
\dot z
=G(z,t)
=\begin{pmatrix}
v\\
-[L v/R+F(x,T(t))]/(LC)
\end{pmatrix}.
```

The thermal pulse is prescribed independently of small phase-space perturbations in the current model.

## 2. Variational matrix

Let

```math
M(t)=\frac{\partial z(t)}{\partial z(0)}.
```

Then

```math
\boxed{
\dot M=A(t)M,
\qquad
M(0)=I,
}
```

with

```math
\boxed{
A(t)=
\begin{pmatrix}
0 & 1\\
-\partial_xF[x(t),T(t)]/(LC) & -1/(RC)
\end{pmatrix}.
}
```

Thus

```math
M(t_f)=D\Phi_{t_f,0}
```

is the Jacobian of the full nonautonomous phase-space flow along the chosen trajectory.

## 3. Pull back the final basin-boundary normal

Let a particular edge trajectory begin on the initial pulled-back basin boundary and end on the final recovered basin boundary.

At the final point `z_f`, let

```math
n_f
```

be a normal covector to the final basin boundary.

Locally, a final perturbation belongs to the tangent boundary if

```math
n_f^T\delta z_f=0.
```

Since

```math
\delta z_f=M(t_f)\delta z_0,
```

we have

```math
n_f^TM(t_f)\delta z_0=0.
```

Therefore the initial pulled-back normal is

```math
\boxed{
n_0=M(t_f)^Tn_f.
}
```

This is the exact linear pullback of the local boundary normal.

## 4. Final cold-saddle normal

If `t_f` is late enough that the edge trajectory lies in the linear neighborhood of the recovered cold saddle, the final tangent stable manifold is generated by the stable eigenvector of the cold linearized matrix.

At the cold saddle, let

```math
\kappa_s=\partial_xF(x_s,T_0)<0.
```

The eigenvalues satisfy

```math
\lambda^2
+\frac1{RC}\lambda
+\frac{\kappa_s}{LC}=0.
```

The stable eigenvalue is

```math
\boxed{
\lambda_-
=-\frac1{2RC}
-\sqrt{
\frac1{4R^2C^2}
+\frac{|\kappa_s|}{LC}
}.
}
```

A tangent vector to the local stable manifold is

```math
e_s^f=\begin{pmatrix}1\\\lambda_-\end{pmatrix}.
```

One convenient normal is therefore

```math
\boxed{
n_f=\begin{pmatrix}-\lambda_-\\1\end{pmatrix}.
}
```

If the chosen final time is not yet asymptotically close to the saddle, the nonlinear final cold stable manifold should be constructed directly rather than using this local approximation.

## 5. Initial boundary slope

Write

```math
n_0=\begin{pmatrix}n_x\\n_v\end{pmatrix}.
```

The local initial basin boundary satisfies

```math
n_x\delta x+n_v\delta v=0.
```

If `n_v != 0`, its shooting-section slope is

```math
\boxed{
\frac{dv_{edge}}{dx}
=-\frac{n_x}{n_v}.
}
```

Thus one boundary shooting point plus one variational integration provides the same local slope that would otherwise require many repeated nonlinear basin searches.

## 6. Quantum covariance-normalized distance

Let the cold initial Wigner covariance be

```math
\Sigma_0.
```

For a mean initial state `mu` and a nearby boundary point `z_b`, define the oriented finite-time basin z-score

```math
\boxed{
Z_B
=\frac{n_0^T(\mu-z_b)}
{\sqrt{n_0^T\Sigma_0n_0}}.
}
```

This is invariant under arbitrary rescaling of `n_0`.

Under a local Gaussian-boundary approximation and deterministic pulse evolution,

```math
P_R^{(init)}\simeq\Phi(Z_B)
```

with orientation chosen so positive `Z_B` points into the target basin.

This is the natural bridge from deterministic finite-time basin geometry to initial-state quantum broadening.

## 7. Why multiple basin strips matter

The first finite-time shooting run indicates that the vertical section `x=x_c` may intersect the pulled-back basin boundary more than once in underdamped regimes.

If multiple boundary branches lie within the support of the cold quantum state, the single-linear-boundary approximation fails.

Then the initial-state capture probability must be computed over the **union of target-basin intervals/regions**:

```math
\boxed{
P_R^{(init)}
=\int_{\Omega_R^0}\rho_W(z)\,d^2z,
}
```

rather than from a single `Phi(Z_B)`.

The variational normal is still useful branch by branch.
