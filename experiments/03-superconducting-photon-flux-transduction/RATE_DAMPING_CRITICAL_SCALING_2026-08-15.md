# Near-Critical Rise-Time / Damping Scaling — 2026-08-15

## Purpose

Compress the full deterministic scalar-R capture boundary near the maximum thermal/electronic rise time that still permits 14-um switching.

The full nonlinear solver shows that as the energy-deposition rise time approaches a critical value from below, the minimum resistance needed to preserve enough nonadiabatic phase motion rises sharply. This checkpoint maps that divergence and gives its local analytical interpretation.

This is a deterministic model result, not a device specification and not a novelty claim.

## 1. Boundary definition

For fixed

```text
A = 100 um^2
lambda = 14 um
current full CPR / realistic-skewness model
conditional clean-graphene cooling
C = current provisional C_min,Q,
```

define `R_min(tau_r)` as the **lowest scalar resistance** for which the full deterministic trajectory is classified in the favored right basin after the pulse.

The numerical boundary is obtained from `calculations/full_dynamic_rfsquid.py` by geometric bracketing followed by bisection.

## 3. Why an inverse-linear divergence is expected

Use the damping parameter

```math
\eta_R\equiv\frac1R.
```

Let the deterministic basin boundary near the weak-damping critical point be described locally by a smooth scalar condition

```math
G(\tau_r,\eta_R)=0.
```

Assume a regular boundary point

```math
G(\tau_c,0)=0,
```

with

```math
G_\tau\ne0,
\qquad
G_\eta\ne0.
```

A first-order expansion gives

```math
0
\simeq
G_\tau(\tau_r-\tau_c)
+G_\eta\eta_R.
```

Hence

```math
\boxed{
\eta_{R,c}
\propto
\tau_c-\tau_r.
}
```

or equivalently

```math
\boxed{
R_{min}
\propto
\frac1{\tau_c-\tau_r}.
}
```

Thus the near-unity fitted exponent is not mysterious. It is the generic local scaling of a smooth capture boundary when resistance enters through the small damping parameter `1/R`.

The physically interesting quantities are therefore

```text
critical zero-damping rise time tau_c
and
first-order boundary coefficient K,
```

not the exponent itself.

## 4. Interpretation of `tau_c`

`tau_c` is the zero-damping / very-weak-damping limit of the current deterministic 14-um rise-time boundary.

It is **not** simply

```text
phase LC time
fold dwell time
or electron-phonon lifetime.
```

It emerges from the complete path-dependent parametric phase work generated by the finite thermal pulse.

The large difference

```text
rDelta=0.8 -> tau_c ~9.63 ps
rDelta=0.6 -> tau_c ~31.29 ps
```

reflects the much larger dynamic energy/basin margin of the lower-fold `rDelta=0.6` family at 14 um.

## 5. Geometry translation

Using only the current characteristic graphene diffusion scale

```math
D_{char}\sim0.705\;m^2/s,
```

the zero-damping rise budgets correspond to simple diffusion lengths

```math
\boxed{d_c\sim\sqrt{D_{char}\tau_c}.}
```

Numerically,

```text
rDelta=0.8 -> d_c ~2.61 um
rDelta=0.6 -> d_c ~4.70 um.
```

These agree with the earlier rough few-micrometre localization requirement but now use the extrapolated dynamic critical rise time rather than a rounded capture estimate.

They remain cross-device design scales, not calibrated transport lengths.

## 6. Strong design consequence

Near `tau_c`, the required scalar resistance diverges. Therefore a design should **not** operate arbitrarily close to its thermal-rise threshold even if nominal deterministic capture remains possible.

A practical deterministic margin can be defined by

```math
\boxed{
\mathcal M_r
=\frac{\tau_c-\tau_r}{\tau_c}.
}
```

Small `M_r` implies extreme sensitivity of required damping to small changes in rise time, geometry, photon landing position or thermal parameters.

For robustness, the operating region should remain at finite `M_r`, not merely satisfy `tau_r<tau_c`.

## 7. What is generic vs detector-specific

The inverse-linear divergence follows from a regular local expansion and is not expected to be publication novelty by itself.

Detector-specific content lies in

```text
tau_c(lambda,A,Delta_ind,CPR,...)
K(lambda,A,environment,...)
upper retrapping boundary
cold dark-stability coupling
and whether the same causal admittance can satisfy launch and capture.
```
