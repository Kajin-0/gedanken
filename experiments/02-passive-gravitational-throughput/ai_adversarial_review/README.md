# Experiment 02 — AI Adversarial Review

## Purpose

This directory implements an **AI-first adversarial review loop** before any final human review.

The theorem branch is frozen while review agents attack the result from incompatible directions. Each role produces a separate immutable report before the meta-referee sees the set.

## Independence warning

These reports use role separation and frozen intermediate outputs, but they are not truly independent human reviews or independently trained-model replications. They should be treated as a high-speed internal adversarial ensemble.

Human input is reserved for the final pre-submission / peer-review stage rather than used as a dependency in the internal research loop.
