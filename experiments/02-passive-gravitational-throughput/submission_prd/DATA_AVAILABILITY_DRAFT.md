# Data Availability Draft — Physical Review D

## Current manuscript statement

Use the scientific statement carried by the PRD manuscript:

> No experimental data were created or analyzed in this work. Numerical verification code supporting the checks reported in Appendix D is available from the author upon reasonable request; those calculations are verification of the analytic results rather than an independent data set.

This wording distinguishes the analytic theorem from the numerical verification layer while addressing APS's current data/software availability policy. The calculations in Appendix D are regression and falsification checks; the analytic derivation remains self-contained.

## Submission-style rule

Do **not** place GitHub, repository names, commit hashes, source-control state, CI/workflow identifiers, internal experiment labels, or other project bookkeeping in the physics article's Data Availability statement.

If the APS submission portal asks separately for code/software availability, use wording consistent with the manuscript: the numerical verification code is available from the author upon reasonable request.

## Human check before submission

Confirm that the final compiled manuscript contains the statement above, identifies Appendix D correctly, and contains no internal project identifiers.
