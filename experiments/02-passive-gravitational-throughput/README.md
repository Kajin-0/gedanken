# Experiment 02 — Passive Gravitational Throughput

**Status:** exploratory; independent reconstruction in progress.  
**Publication status:** none.  
**Manuscript:** none yet.

## Purpose

This experiment asks whether propagating linearized gravity imposes a frequency-integrated throughput ceiling on two separated compact passive matter systems that can be written only in terms of endpoint mechanical resources and free-space separation.

A previous conversational exploration suggested the candidate scaling

```math
\Gamma_{\rm coh}
\stackrel{?}{\lesssim}
\frac{25G\omega^2}{12c^3R^2}\min(I_A,I_B),
```

but **this is not a result of the repository yet**. The coefficient, hypotheses, and even the existence of an inertia-only bound are provisional until independently re-derived and attacked from the files in this directory.

The question is intentionally separated from Experiment 01. The V7 manuscript in `../01-causal-quantum-branch-information/` remains frozen except for submission/editorial work or a concrete technical defect.

## Research rule

Do not reconstruct a desired theorem from memory. Start from the physical question and attempt to derive, weaken, or falsify the candidate statement.

The required sequence is:

1. independent derivation from explicit assumptions;
2. normalization and dimensional audit;
3. adversarial mathematical/physical attack;
4. primary-source prior-art collision search;
5. numerical counterexample search where possible;
6. only after those survive, consider a manuscript.
