# Gravitational Port Factorization

## 1. Purpose

A multimode gravitational transducer contains two distinct pieces of physics:

1. **how strongly matter couples to the graviton field**;
2. **which normalized gravitational field modes those couplings populate or absorb**.

If those pieces are not separated carefully, the endpoint gravitational linewidth and the free-space mode-overlap factor can be double counted.

This note gives a clean operator factorization showing that the passive-network resource `K_g^dagger K_g` and the propagation map `P_g` are different factors of the same microscopic matter-field coupling problem.

---

## 2. Microscopic coupling operator

Fix a sufficiently narrow frequency sector so that Markov normalization is valid. Let

```math
\mathcal H_m
```

be the finite-dimensional endpoint matter-mode space and

```math
\mathcal H_g
```

be the one-graviton radiation-channel Hilbert space for that sector, including angular direction and TT polarization.

The rotating-wave matter-to-graviton coupling can be represented by a linear operator

```math
\boxed{
G_A:\mathcal H_{m,A}\to\mathcal H_g.
}
```

For matter amplitude vector `x`, the field coupling vector is

```math
G_A x\in\mathcal H_g.
```

The gravitational damping matrix is the Gram operator

```math
\boxed{
\Gamma_{g,A}=G_A^\dagger G_A.
}
```

In an input-output realization we may choose a finite orthonormal basis of the radiative subspace `Ran(G_A)` and identify

```math
K_{g,A}^\dagger K_{g,A}=G_A^\dagger G_A.
```

Therefore

```math
\boxed{
\operatorname{Tr}(K_{g,A}^\dagger K_{g,A})
=\|G_A\|_F^2,
}
```

the total microscopic gravitational coupling strength of the retained matter sector.

The receiver has an analogous operator

```math
G_B:\mathcal H_{m,B}\to\mathcal H_g.
```

## 3. Polar decomposition

Take the polar decomposition

```math
\boxed{
G_A=V_A\Gamma_{g,A}^{1/2},
}
```

where `V_A` is a partial isometry from the gravitationally bright matter subspace into the normalized radiative-mode subspace of `H_g`.

Likewise,

```math
\boxed{
G_B=V_B\Gamma_{g,B}^{1/2}.
}
```

This separates:

```text
Gamma_g^(1/2)  = coupling magnitude / linewidth resource
V              = normalized angular-polarization mode shape
```

The factorization is basis independent.

Internal coherent mixing changes the representation of `Gamma_g` and `V` but cannot change

```math
\operatorname{Tr}\Gamma_g
```

without changing the physical matter-gravity coupling itself.

## 4. Free propagation between normalized gravitational port spaces

Let

```math
U_R(\omega)
```

be free retarded propagation/translation of the graviton field from the source origin to the receiver origin at fixed frequency. On the complete free-field Hilbert space this propagation is norm preserving.

The finite-dimensional normalized propagation map seen by the two material interfaces is

```math
\boxed{
P_g(\omega)
=V_B^\dagger U_R(\omega)V_A.
}
```

Hence

```math
\boxed{
\|P_g(\omega)\|_{\rm op}\le1
}
```

before any compact-source geometric refinement.

The complete microscopic source-to-receiver gravitational coupling has the form

```math
\boxed{
G_B^\dagger U_R G_A
=
\Gamma_{g,B}^{1/2}
P_g
\Gamma_{g,A}^{1/2}.
}
```

This is the operator version of the V7 decomposition

```text
source gravitational branching
x normalized propagation overlap
x receiver gravitational branching.
```

It makes clear that the coupling magnitudes and propagation overlap are not duplicate normalizations.

## 5. Nonorthogonal radiation patterns are automatically handled

Different matter modes can radiate nonorthogonal gravitational angular patterns. No assumption of one orthogonal bath channel per material mode is required.

If the microscopic coupling vectors are

```math
g_n\in\mathcal H_g,
```

then

```math
(\Gamma_g)_{mn}
=\langle g_m,g_n\rangle.
```

Off-diagonal entries describe collective radiative damping/interference. Nevertheless,

```math
\boxed{
\operatorname{Tr}\Gamma_g
=\sum_n\|g_n\|^2
}
```

in any orthonormal matter basis.

The partial isometry `V` orthonormalizes only the **bright radiative subspace**; it does not pretend that the original radiation patterns were independent.

This resolves the multimode version of the source-port normalization issue.

## 6. Compact quadrupole specialization

For compact mass-quadrupole radiation at fixed frequency, every microscopic coupling vector in `H_g` is generated by an STF transition tensor `Q`:

```math
u_{Q,\lambda}(\hat n)
\propto
Q:\epsilon^{(\lambda)}(\hat n).
```

A coherent superposition of material modes produces a coherent superposition of their transition tensors, which is again an STF tensor. Therefore the entire radiative bright subspace remains inside the five-dimensional `l=2` STF quadrupole family.

The translated overlap between any normalized source and receiver vectors in these bright subspaces is therefore bounded by `TT_PROPAGATION_BOUND.md`:

```math
\boxed{
\|P_g(\omega)\|_{\rm op}
\le
\frac{5}{4kR}
+O((kR)^{-2}),
}
```

and

```math
\boxed{
\|P_g(\omega)\|_{\rm op}^2
\le
\frac{25}{16(kR)^2}
\left[1+O((kR)^{-1})\right].
}
```

Thus the compact-quadrupole geometry factor acts on the **normalized radiative subspaces after coupling magnitude has been factored out**.


The microscopic quadrupole transition formula and EWSR then give

```math
\boxed{

\le
```

for the retained compact nonrelativistic quadrupole-active modes below operating ceiling `Omega`.

The theorem therefore has a clean three-factor structure:


with no double counting.

## 9. Direct-feedthrough caveat

A general abstract scattering model may contain a static unitary feedthrough matrix mixing input and output ports. A nonzero direct local-to-gravitational feedthrough would represent an additional physical conversion element not mediated by the matter modes whose quadrupole resource is being bounded.

The Experiment 02 theorem therefore assumes no unaccounted direct useful-local-to-gravitational feedthrough. If such a converter exists, it must be included as another physical subsystem, with its own gravitational coupling/resource accounting.

This is a scope condition, not a mathematical omission.

## 10. Band-local interpretation

Because the gravitational density of states and quadrupole coupling vary strongly with frequency, `G`, `Gamma_g`, `V`, and `P_g` should be interpreted within a sufficiently narrow frequency sector.

For widely separated resonances, use a direct sum of local sectors or the eventual non-Markov susceptibility formulation. The cumulative EWSR bounds the sum of the sector resources.

Do not interpret one constant Markov coupling matrix as exact over an arbitrarily broad spectrum.
